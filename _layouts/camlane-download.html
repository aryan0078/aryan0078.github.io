      Set up

      {% if page.os == 'windows' %}
      1. Run the installer. SmartScreen may warn because the app isn't code-signed yet. Choose More info, then Run anyway.
      2. For the virtual camera, install OBS Studio once. Camlane uses its virtual camera driver, and OBS doesn't need to stay open.
      3. For the virtual microphone, install VB-Cable and choose CABLE Input as Camlane's audio output.
      4. Open Camlane on your phone, tap this PC and enter the PIN shown in the desktop app.
      {% elsif page.os == 'macos' %}
      1. Open the disk image and drag Camlane to Applications. The app isn't notarised yet, so the first time, right-click it and choose Open.
      2. For a virtual microphone, install BlackHole and choose it as Camlane's audio output.
      3. Open Camlane on your phone, tap this Mac and enter the PIN shown in the desktop app.
      {% elsif page.os == 'linux' %}
      1. Install the virtual camera module once: 
        sudo apt install v4l2loopback-dkms
sudo modprobe v4l2loopback devices=1 video_nr=10 card_label="Camlane Camera" exclusive_caps=1
      2. For the AppImage, run chmod +x camlane-desktop-linux-x86_64.AppImage and open it. For the package, run sudo apt install ./camlane-desktop-linux-x86_64.deb.
      3. Open Camlane on your phone, tap this computer and enter the PIN. In your call app, choose Camlane Camera and Camlane Microphone.
      {% elsif page.os == 'android' %}
      1. Install Camlane. If you use the APK, allow your browser to install apps when Android asks.
      2. Install the desktop app on your computer: Windows, macOS or Linux.
      3. Keep the phone and computer on the same Wi-Fi, open Camlane and tap your computer.
      {% endif %}
