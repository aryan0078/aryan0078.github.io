{% if page.os == 'windows' %}

Set up on Windows

  1. Run the installer. SmartScreen may warn because the app is not code-signed yet: choose More info → Run anyway.
  2. For the virtual camera, install OBS Studio once. Camlane uses its Virtual Camera driver; OBS does not need to stay open.
  3. For the virtual microphone, install VB-Cable and pick CABLE Input as Camlane's audio output.
  4. Open Camlane on your phone, tap this PC, and enter the PIN shown in the desktop app.
{% elsif page.os == 'macos' %}

Set up on macOS (beta)

  1. Open the .dmg and drag Camlane to Applications. The app is not notarised yet: right-click it and choose Open the first time.
  2. For a virtual microphone, install BlackHole and pick it as Camlane's audio output.
  3. Open Camlane on your phone, tap this Mac, and enter the PIN shown in the desktop app.
{% elsif page.os == 'linux' %}

Set up on Linux

  1. Install the virtual camera module once: 
    sudo apt install v4l2loopback-dkms
sudo modprobe v4l2loopback devices=1 video_nr=10 card_label="Camlane Camera" exclusive_caps=1
  2. AppImage: chmod +x camlane-desktop-linux-x86_64.AppImage and run it. Debian/Ubuntu: sudo apt install ./camlane-desktop-linux-x86_64.deb.
  3. Open Camlane on your phone, tap this computer, and enter the PIN. Pick Camlane Camera and Camlane Microphone in your call app.
{% elsif page.os == 'android' %}

Set up on Android

  1. Install Camlane. If you use the APK, allow your browser to install unknown apps when asked.
  2. Install the desktop app on your computer: Windows, macOS or Linux.
  3. Keep both on the same Wi-Fi, open Camlane on the phone and tap your computer.
